# Автотесты

119 тестов чистых функций: без окон, сети и системы. Запуск одной командой, код выхода 0 — всё прошло:

```bash
MSYS_NO_PATHCONV=1 "/c/Program Files/AutoHotkey/v2/AutoHotkey64.exe" /ErrorStdOut tests/run.ahk | cat
```

Те же тесты прогоняет GitHub Actions перед каждой сборкой релиза. Новый файл тестов подключается в `run.ahk`, а этот список обновляется вместе с ним.

## Ядро — `CoreTests.ahk`

**Маппинг раскладки (9):** RU, US, GB, UA, BY, KZ; вариант раскладки (Дворак) — флаг по языку; нет картинки — только текст; числовой регион (en-029) — только текст.

**Позиция у каретки (8):** снизу — левый край на вертикали каретки; сверху; справа и слева — по центру; четыре угла.

**Decide (12):**
- по умолчанию флажок под кареткой, 16×12, отступ 3;
- скругление растёт вместе с размером;
- DPI 125%, 150%, 200%;
- скрыто: нет каретки, индикатор выключен, раскладка неизвестна;
- нет картинки — размещение с текстом;
- `show = code` у каретки — плашка вместо флага; `show = code` у мыши — каретка остаётся с флагом;
- плашка шире для длинного кода.

**Флажок у мыши (10):**
- по умолчанию справа снизу от видимой «I», отступ 3;
- границ глифа нет — якорь по hotspot;
- скрыто: курсор не IBEAM, курсора нет, индикатор выключен;
- снизу — по левому краю «I»; слева — по центру «I»;
- DPI 150%;
- мышь и каретка независимы;
- у мыши тот же флаг, что у каретки (раскладка активного окна).

**Полноэкранный режим (4):** окно на мониторе флажков — оба скрыты; на другом мониторе — видны; опция выключена — видны; полноэкранного окна нет — видны.

**Размер по высоте каретки (6):** 70% от высоты; упор в максимум и минимум; DPI 150% — в логических пикселях; флажок у мыши не меняется; фиксированный размер не зависит от каретки.

## Настройки — `SettingsTests.ahk`

**Чтение и запись ini (6):** файла нет, пустой файл, мусорные значения — значения по умолчанию; сохранить и прочитать — то же самое; значения по умолчанию переживают сохранение; ручная правка в нижнем регистре и с пробелами.

**Переопределения раскладок в ядре (5):** US → флаг GB; Дворак отдельно от US; нет картинки — плашка со своим кодом; только по полному HKL; переопределения доходят до `Core.Decide`.

**Изменение из окна — `Set` (14):**
- годное число; число вне пределов отброшено; булево;
- сторона в любом регистре; вложенный путь;
- цвет фона кода в любом регистре, `none`, негодный цвет отброшен; негодный шрифт отброшен;
- язык окна из списка и не из списка;
- `show` — только `flag` или `code`;
- неизвестный ключ; максимум размера не меньше минимума.

**Переопределение раскладки из окна — `SetLayout` (5):** флаг и код; без флага; код обрезается до 4 знаков и без `|`; негодный флаг отброшен; оба пустые — переопределение снято.

**Где лежит settings.ini (3):** из исходников — рядом со скриптом; установленная программа — в `%AppData%`; портабельная — рядом с программой.

**Настройки обновлений (3):** галочка «Автообновление»; служебные значения окну не меняются; `[Update]` читается и проверяется.

## Что автотестами не покрыто

Это адаптеры к системе — их проверяют руками по [чеклисту программ](../docs/app-checklist.md), а итоги записывают в комментарии к тикетам:

- поиск каретки (Win32, MSAA, UIA) и раскладки в разных программах — `src/Probes.ahk`;
- рисование флажка и плашки — `src/Overlay.ahk`, `src/Gdip.ahk` (центровку кода проверяли снимками);
- окно настроек и мост со страницей — `src/SettingsPage.ahk`, `ui/`;
- загрузчик WebView2 — `src/WebView2Runtime.ahk`;
- сеть, скачивание и установка обновления — `src/Http.ahk`, сетевая часть `src/Updater.ahk` (сквозная проверка — на тестовом источнике через `[Update] feed`);
- автозапуск — `src/Autostart.ahk`;
- сборка, установщик и релиз — `build/`, `.github/workflows/release.yml`.
